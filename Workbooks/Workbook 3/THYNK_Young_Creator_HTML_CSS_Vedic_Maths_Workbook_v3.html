Welcome, Young Creator!
Hi there! I’m THYNK BOT, and I’ll be popping up on every page to help, hint, and cheer you on. Ready to build your very first website?

This workbook is not really about learning ‘computer rules.’ It’s about turning an idea inside your head into something real that anyone in the world could visit. Along the way, your Vedic Maths tricks will help you think faster, sharper, and more confidently — on the page AND on the screen.

Vedic Maths helps you think about numbers.
HTML helps you structure your ideas.
CSS helps you make your ideas beautiful.

Here’s the journey you’re about to go on:

THINK → CALCULATE → PLAN → CODE → DESIGN → TEST → IMPROVE → CREATE → SHARE

By the end, you won’t just know some HTML and CSS — you’ll have proof, in your own website, that you can turn an idea into something real.
