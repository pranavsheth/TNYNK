# THYNK Young Creator
## HTML + CSS × Vedic Maths
### Grade 4–5 | 24 Periods × 35 Minutes

---

## 1. The Overall Concept

This workbook should not feel like a conventional HTML/CSS course. Since HTML and CSS are the students' **first real coding experience**, the goal is to make them feel:

> **“I can create a webpage!”**

rather than:

> **“I am learning programming syntax.”**

The learning journey is:

**Think → Calculate → Plan → Code → Design → Create → Improve → Share**

### Core THYNK idea

> **Vedic Maths helps you think about numbers.  
> HTML helps you structure your ideas.  
> CSS helps you make your ideas beautiful.**

The workbook should use small **Math + Code** challenges throughout the course so that Coding and Vedic Maths reinforce each other naturally.

---

# 2. 24-Period Structure

**24 periods × 35 minutes = 840 minutes = 14 hours**

| Module | Periods | Main Learning |
|---|---:|---|
| 1. Meet the Web | 2 | What is a website? |
| 2. My First HTML | 3 | HTML basics |
| 3. Build My First Page | 3 | Text, headings, lists |
| 4. Maths on the Web | 2 | Numbers + HTML |
| 5. Make It Beautiful | 3 | CSS basics |
| 6. Colours, Fonts & Boxes | 3 | CSS styling |
| 7. Vedic Maths Webpage | 2 | Maths + design project |
| 8. Build a Mini Website | 4 | Independent project |
| 9. Showcase & Challenge | 2 | Final project + presentation |
| **Total** | **24** | |

### Important

JavaScript should **not** be introduced at this level.

The objective is to make students comfortable with coding, logic, creativity, problem-solving and computational thinking.

---

# 3. Workbook Philosophy

Every lesson should follow the same visual pattern.

### Every lesson has:

**1. THINK 💡**  
A simple question.

**2. DISCOVER 🔍**  
Introduce one new concept.

**3. TRY 💻**  
Student types a tiny piece of code.

**4. CREATE 🎨**  
Student builds something visible.

**5. MATH LINK 🧮**  
A short Vedic Maths activity.

**6. CHALLENGE 🚀**  
One optional extension.

This consistency will make the workbook easy for Grade 4–5 students to follow.

# PART 1 — MEET THE WEB

## Period 1 — Welcome to the World of Websites

### Concept

Start without code.

Explain:

**What is a website?**

Use examples children already know:

- YouTube
- Google
- Wikipedia
- Online games
- School website
- Shopping websites

### Simple explanation

> A website is like a digital book.  
> HTML tells the browser **what is on the page**.  
> CSS tells the browser **how it should look**.

### Activity

Show a webpage and ask students to identify:

- Heading
- Picture
- Paragraph
- Button
- List
- Colour

### THINK

If you were creating your own website, what would it be about?

- My School
- My Favourite Sport
- Space
- Animals
- Maths
- Games
- My Hobby

## Period 2 — HTML Is the Skeleton

Introduce the concept of a webpage having a structure.

### Analogy

**Human body**

**Skeleton → HTML**

**Clothes → CSS**

### First structure

```html

<head>
</head>

<body>

</body>
</html>
```

Explain:

> `<body>` is where the things we see on the webpage go.

# PART 4 — MATHS ON THE WEB

This is where Coding and Vedic Maths begin to connect deliberately.

## Period 9 — Numbers Become Content

Introduce the idea that HTML can display mathematical information.

Example:

```html
<h1>My Maths Challenge</h1>

<p>25 × 4 = 100</p>
```

Students can display their Vedic Maths answers on a webpage.

Example:

```html
<h2>My Score</h2>

<p>Round 1: 18</p>
<p>Round 2: 25</p>
<p>Round 3: 32</p>
```

### Vedic Maths Connection

Give students 5 mental-maths questions.

Examples:

- 25 × 4 = ?
- 50 × 6 = ?
- 125 × 8 = ?

Students solve them using the Vedic Maths techniques they have learned.

Then:

> **Code your answers into your webpage.**

The connection is:

**Vedic Maths → THINK**

**HTML → PRESENT**

## Period 16 — The Magic of Spacing

Teach:

**Padding = space inside the box**

**Margin = space outside the box**

### Math connection

Use simple visual problems.

Example:

> A card is 300px wide. Padding on each side is 20px. How much space is left for the content?

Keep the calculations simple.

### Vedic Maths Challenge

- 25 + 25 + 25 + 25 = ?
- Four boxes are each 25px apart. How much total space?

The objective is to reinforce mental calculation and spatial thinking.

# 10. How Vedic Maths and Coding Are Inter-Related

The connection should be broader than simply putting maths questions on a webpage.

## Connection 1 — Numbers

Students calculate something in Vedic Maths and represent it using HTML.

**Calculate → Code**

---

## Connection 2 — Patterns

Vedic Maths involves patterns.

Coding also involves patterns.

Example:

```text
5 × 2 = 10
5 × 4 = 20
5 × 6 = 30
5 × 8 = 40
```

Ask:

> What pattern do you see?

Then:

> How would you display this pattern on your webpage?

This develops pattern recognition.

---

## Connection 3 — Accuracy

Vedic Maths:

> Did I calculate correctly?

Coding:

> Did I write the code correctly?

Both require:

**Attention → Check → Correct**

This naturally introduces debugging.

---

## Connection 4 — Problem Solving

Vedic Maths:

> How can I solve this calculation faster?

Coding:

> How can I create this webpage?

Both teach:

**Break a problem into smaller steps.**

This supports computational thinking.

# 12. Recommended HTML Vocabulary

Keep the coding vocabulary intentionally small.

### HTML

```text
html
head
body
h1
h2
h3
p
ul
li
img
a
div
```

### CSS

```text
color
background-color
font-size
font-family
text-align
border
padding
margin
```

Avoid introducing at this level:

- JavaScript
- CSS Grid
- Flexbox
- Responsive design
- Complicated selectors
- Classes in depth
- IDs
- Animations
- Forms
- Media queries

These can come in later THYNK levels.
