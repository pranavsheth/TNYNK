Teacher Notes — Teaching Principles
05

Keep the experience light

  • Never introduce more than one major new coding idea in a single class.
  • Let students type and change code themselves; avoid long copying exercises.
  • Show the result immediately after each small change.
  • Celebrate errors as clues, not failures.
  • Pair faster students with a challenge rather than giving them more theory.
  • For students who need support, provide a partially completed code block.

Vedic Maths integration

The workbook does not assume a particular Vedic Maths syllabus. Use the Vedic technique already being taught in your THYNK class and adapt the questions accordingly.

Core connection: Vedic Maths develops speed, accuracy, patterns and flexible thinking. Coding asks students to use those same habits when planning, typing and debugging.

What students should NOT learn yet

Do not add JavaScript, Flexbox, Grid, media queries, complex selectors, forms or animations in this level.

🔍 DISCOVER

🔍 DISCOVER

Spacing helps a page breathe. Without space, everything feels crowded. With the right space, information is easier to read.

HTML

🚀 LEVEL UP

Teacher Note

HTML Toolbox
31
HTML is your webpage structure.
ToolWhat it doesExample
h1Main heading
<h1>My Title</h1>
h2Section heading
<h2>My Section</h2>
h3Smaller heading
<h3>My Topic</h3>
pParagraph
<p>My sentence goes here.</p>
ulBullet list
<ul> ... </ul>
liList item
<li>One idea</li>
imgImage
<img src="cat.jpg" alt="A cat">
aLink
<a href="https://example.com">Visit</a>
divGroup / box
<div> ... </div>
Tip: Change one thing at a time. Then look at the webpage and see what happened.

CSS Toolbox
32
CSS changes how your HTML looks.
ToolWhat it doesExample
colorText colour
h1 { color: blue; }
background-colorBackground
body { background-color: lightblue; }
font-sizeText size
h1 { font-size: 40px; }
font-familyFont
p { font-family: Arial; }
text-alignAlignment
h1 { text-align: center; }
borderLine around a box
.card { border: 2px solid navy; }
paddingSpace inside
.card { padding: 20px; }
marginSpace outside
.card { margin: 20px; }
Tip: Change one thing at a time. Then look at the webpage and see what happened.
