Chapter 1.2

Dance Loop

Mini-project file: book2_ch1_mini_dance_loop.sb3
Lesson goal (30-40 min): Build a dance animation using sequence, loop, costume switch, and timing control.
What to demo first
  1. Run once and identify repeated pattern.
  2. Show block order: repeat -> turn -> move -> next costume -> wait.
  3. Change values live: wait 0.2 to 0.1, move 15 to 30.
  4. Re-run and compare smoothness.
Common errors and quick fixes
  • Jumpy movement: reduce move + wait together.
  • Stops too early: increase repeat count.
  • No costume animation: keep next costume inside loop.
  • Sprite drifts away: add edge bounce or lower movement.
Troubleshooting checklist
  1. Is when green flag clicked at top?
  2. Does repeat wrap all action blocks?
  3. Is wait inside loop?
  4. Are at least two costumes available?
Exit ticket: Which single block change made the biggest visual difference, and why?
Chapter 2.2

Pattern Artist

Mini-project file: book2_ch2_mini_pattern_artist.sb3
Lesson goal (30-40 min): Use custom blocks with inputs for reusable geometric pattern logic.
What to demo first
  1. Run once and observe repeated behavior.
  2. Show custom blocks: drawLine(len), turnAngle(deg).
  3. Show where both blocks are called in repeat.
  4. Change turn angle 60 to 45 and compare output.
Common errors and quick fixes
  • Nothing drawn: check pen down before loop.
  • Messy random lines: start with clear and reset position.
  • Input ignored: ensure argument reporter is used in definition.
  • Script too long: move repeated logic into custom blocks.
Troubleshooting checklist
  1. Is pen extension enabled?
  2. Is pen clear at start?
  3. Is pen down before repeat?
  4. Do custom blocks use their input parameters?
Exit ticket: Why are custom blocks better than copy-pasting long block chains?
Chapter 3.2

One-Minute Story

Mini-project file: book2_ch3_mini_one_minute_story.sb3
Lesson goal (30-40 min): Build a short story with timed dialogue, scene transitions, sprite movement, and sound.
What to demo first
  1. Run full story once.
  2. Replay and pause at scene transitions.
  3. Show sequence: say for seconds -> broadcast -> wait.
  4. Modify one timing value and test clarity.
Common errors and quick fixes
  • Dialogue overlap: use say for seconds + short waits.
  • Scene not starting: verify exact message spelling.
  • Sound timing off: use play sound until done.
  • Story confusing: one event and one transition per scene.
Troubleshooting checklist
  1. Does each scene end with one clear trigger?
  2. Do all receivers match message names exactly?
  3. Are waits inserted between major actions?
  4. Are beginning and ending lines clearly visible?
Exit ticket: Which block most improved story clarity: wait, say duration, or broadcast?
Chapter 4.2

Final Showreel

Mini-project file: book2_ch4_mini_final_showreel.sb3
Lesson goal (40 min): Combine animation, custom blocks, sound/story flow, and broadcasts into one polished project.
What to demo first
  1. Run full showreel and identify all four concepts.
  2. Show message chain: intro_done -> demo_start -> show_end.
  3. Show receiver scripts and custom jump block.
  4. Change one value live and retest.
Common errors and quick fixes
  • After renaming message, flow breaks: update all senders/receivers.
  • Custom block fails: verify call input and definition reporter.
  • Too many simultaneous actions: add waits between broadcasts.
  • No ending: confirm show_end broadcast and receiver exist.
Troubleshooting checklist
  1. At least 3 broadcast messages?
  2. At least one custom block with input?
  3. Visible costume animation with timing?
  4. At least one sound integrated in flow?
Exit ticket: Name one bug fixed today and the concept you used best.
