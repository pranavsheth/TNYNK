# THYNK Book 2 - Teacher Reference Scratch Programs

These Scratch files are mapped to the Chapter example sections in:
`Workbooks/Beginners Basic 2/THYNK_workbook_beginners_basic_2.html`

## Files

- `book2_ch1_animation_example.sb3`
  - Chapter 1.1 example script: walking animation (`repeat -> next costume -> move -> wait`)

- `book2_ch2_custom_block_jump_example.sb3`
  - Chapter 2.1 example with input: custom block `jump(height)`
  - Includes calls for a small jump (`20`) and a big jump (`50`)

- `book2_ch3_story_timeline_example.sb3`
  - Chapter 3.1 example scene timeline
  - Includes dialogue, sound timing, movement, wait, and a scene transition broadcast

- `book2_ch4_broadcast_chain_example.sb3`
  - Chapter 4.1 example broadcast chain
  - Includes controller and responder sprites using `scene1` and `scene2` messages

- `book2_ch1_mini_dance_loop.sb3`
  - Chapter 1.2 mini-project reference (Dance Loop)

- `book2_ch2_mini_pattern_artist.sb3`
  - Chapter 2.2 mini-project reference (Pattern Artist)
  - Uses two custom blocks with inputs and pen extension

- `book2_ch3_mini_one_minute_story.sb3`
  - Chapter 3.2 mini-project reference (One-Minute Story)
  - Uses sprites, dialogue, sound, and scene broadcasts

- `book2_ch4_mini_final_showreel.sb3`
  - Chapter 4.2 final project reference (Scratch Showreel)
  - Combines animation, custom block, sound, and broadcasts

## How to use in class

1. Open any `.sb3` file in Scratch.
2. Click green flag to run.
3. Show students the script flow, then ask them to modify one parameter (speed, message name, or timing) and observe behavior.
