Program Structure

Two tracks. One connected story.

Every session pairs a Vedic technique with the coding concept that mirrors it — so the maths teaches the code and the code teaches the maths.

Grades 4 & 5

Vedic Maths + Scratch

Block-based coding by MIT — used by 100M+ children worldwide. Kids skip typing syntax and focus on logic and creativity.

  • Sequencing & Events — the foundation of every program ever written.
  • Loops mapped to Ekadhikena Purvena (“by one more than the previous”).
  • Variables, lists & conditionals — score a live Vedic-maths quiz.
  • Custom Blocks — package a sutra into a reusable function.
  • Sprites, sound, broadcasting — event-driven programming, made visual.

Sample projects: Guess My Number · Nikhilam Wizard · Times-Table Race · Urdhva Multiplication Machine · a final original game every student presents.

Grades 6 & 7

Vedic Maths + HTML · CSS · JavaScript

Real web programming — the same three languages that build Google and Instagram. No toys, no training wheels: by week 24 they’ve published a real website.

  • HTML — semantic structure, forms, inputs; the skeleton of the web.
  • CSS — selectors, layout, responsive design; the clothing.
  • JavaScript — variables, loops, functions = Vedic unknowns, patterns, sutras.
  • Interactive Vedic tools — calculators, animated sutra visualisers, mini-quizzes.
  • AI prompting basics — how to talk to AI as a co-builder, not an answer machine.

Sample capstones: a personal cricket run-rate site · an interactive Vedic-adventure page · a maths-quiz web app that scores itself.

FAQ

The questions schools ask us first.

Do we need to hire a specialist coding teacher?

No. T.H.Y.N.K is designed to be delivered by your existing computer/maths teacher. Every session is scripted, we run initial training, and there is a monthly refresher included.

What infrastructure do we need?

Just a functional computer lab with one machine per child (or per pair) and a browser. Scratch and our web tools are 100% browser-based. No installs.

How is this different from a Vedic-maths tuition or a coding bootcamp?

Both exist in isolation. T.H.Y.N.K is the only program that teaches them as one thinking skill — using each subject to reinforce the other, inside the regular school week.

Is AI safe for a 9-year-old?

Yes, when framed as a thinking partner. Our teacher guide has a dedicated chapter on age-appropriate AI prompting: what to ask, what not to share, and how to treat AI as a co-builder, not an answer machine.

Does it align with NEP 2020?

Fully. NEP 2020 calls for computational thinking, coding, and digital fluency from middle school. Our curriculum, workbooks, and progress reports are mapped to it and audit-ready.
